# HR Analytics Dashboard

## Overview
This project is an end-to-end HR Analytics Dashboard built using Power BI to analyze workforce trends, employee performance, hiring growth, and organizational attrition patterns using a dataset containing over 2 million employee records.

The dashboard helps HR teams and business stakeholders monitor workforce KPIs, evaluate department performance, and support data-driven decision-making through interactive visual analytics.

---

# Project Objectives
- Analyze workforce distribution across departments
- Monitor employee attrition and status trends
- Evaluate employee performance distribution
- Track hiring growth over time
- Build executive-level HR reporting
- Deliver actionable workforce insights

---

# Key Insights
- Sales emerged as the largest department by workforce size.
- Hiring trends accelerated significantly after 2020.
- Most employees fall under the “Good” performance category.
- Active employees dominate the workforce, while attrition trends indicate areas requiring retention analysis.
- Workforce distribution varies heavily across departments and job levels.
